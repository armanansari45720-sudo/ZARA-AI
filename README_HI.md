# ZARA AI – शुरुआती Android प्रोजेक्ट

यह एक शुरुआती Android Studio प्रोजेक्ट है। इसमें:
- Hindi voice input (माइक दबाकर बोलना)
- फोन की Text-to-Speech आवाज़ में जवाब
- समय और तारीख बताना
- YouTube, WhatsApp, Instagram और Camera खोलने के बेसिक कमांड

## APK कैसे बनाएं
1. कंप्यूटर पर Android Studio इंस्टॉल करें।
2. इस ZIP को Extract करें।
3. Android Studio में `ZARA_AI_Android_Project` फ़ोल्डर खोलें।
4. Gradle Sync पूरा होने दें।
5. फोन को USB से जोड़ें या Emulator चुनें।
6. Run दबाकर टेस्ट करें।
7. APK के लिए: Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।

## जरूरी सीमाएँ
- यह अभी पूरा AI चैटबॉट नहीं है; AI API/backend अभी जोड़ना बाकी है।
- "Hello Zara" wake word और लॉक-स्क्रीन पर लगातार सुनना अभी शामिल नहीं है।
- लॉक स्क्रीन को बायपास नहीं किया जाता। संवेदनशील कामों के लिए फोन अनलॉक करना होगा।
- Android Studio चलाने के लिए कंप्यूटर की ضرورت होगी। केवल ZIP डाउनलोड करने से APK नहीं बनता।
- API keys को ऐप के अंदर सीधे न रखें; सुरक्षित backend की जरूरत होगी।
